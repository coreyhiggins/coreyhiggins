I founded Wynfall Studios. I train the Wynfall model family on GPUs I run myself, and I build the products around it: Sigel, Ken, and Nova. Writing, reasoning, code.

Most of that work stays closed. When a problem turns out to be general rather than ours, I publish the fix. Those tools are below.


What I ship

blastradius

Sits in front of an agent's shell and answers one question before the command runs: how far does this reach?

File edits can be undone. terraform destroy cannot.

npx @coreyhiggins/blastradius install

grain

Routes each prompt to the right discipline and injects only the matching guidance. Zero tokens on conversational turns.

Every claim is benchmarked, including the ones that failed.

npx @coreyhiggins/grain

Smaller things

Small, zero-dependency tools. Each one exists because something bit me once.
proofmark Backtest engine whose defaults make self-deception expensive. Suppresses impossible results, tests every bar for lookahead, counts your trials.
tanto Measured Windows performance tuning with reversible changes and evidence from your own machine.
jvm-shutdown-watchdog Forces a wedged JVM to exit and reports which threads wedged it.
failsoft-webhook Posts alerts to a webhook without taking down the app sending them.
linux-deploy-toolkit Versioned releases, atomic symlink swap, health check, automatic rollback.
service-health-monitor Endpoint and systemd monitoring on a timer, with state-change alerts.
mcp-server-example Dependency-free Model Context Protocol server over stdio.
